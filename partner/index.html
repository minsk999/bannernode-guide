배너에 영상을 —
노드로 연결하면 끝.근데 이제 컷 편집, BGM 믹스, 사이즈·용량·포맷 베리를 곁들인

BannerNode는 배너 PNG의 투명하게 뚫린 구멍에 영상을 합성해 넣는 데스크톱 앱이에요. 영상 노드와 배너 노드를 선으로 잇기만 하면 렌더 잡 하나가 만들어지고, ffmpeg로 내 PC에서 바로 렌더합니다.

01

노드 연결 · 렌더

BannerNode의 핵심. 영상 노드에서 배너 노드로 선을 이으면 그 조합이 렌더 잡이 됩니다.

  1. 노드 배치 — 영상·배너 카드를 캔버스로 드래그해 노드로 만들어요.
  2. 선 연결 — 영상 노드의 출력점에서 배너 노드로 드래그해 연결. 연결 1개 = 렌더 잡 1개.
  3. 구도 잡기 · 선택 — 렌더큐 대기 카드의 썸네일을 클릭하면 합성 미리보기가 열려요. 배너 구멍 안의 영상을 드래그해 위치를 옮기고 휠로 확대할 수 있습니다. 기본은 구멍을 가득 채우는 가운데 맞춤이고, 휠(가운데) 클릭이면 위치·확대가 한 번에 초기화돼요. 여기서 잡은 구도는 렌더 결과에 그대로 반영됩니다.
    오른쪽 패널에는 크기 슬라이더(% 숫자를 누르면 0.1% 단위로 직접 입력 · Enter 적용 · Esc 취소) · [전체 보이기] · [꽉 채우기] · 위치 9칸(구멍 안 기준) · [초기화]가 있어요. 끌면 자석처럼 구멍 가장자리·가운데에 붙고, 크기는 「꽉 채우기」와 「전체 보이기」에서 한 번 멈춰요 — ⇧를 누르면 자석 없이 움직입니다. 구멍보다 작게 줄이면(최소 10%) 빈 곳은 같은 영상을 흐리게 깔아 채워요. [같은 배너 전체에 적용]은 지금 크기·위치를 이 배너를 쓰는 다른 카드에도 똑같이 넣습니다.
    같은 배치 함께 맞추기 · 처음엔 켜져 있음 — 패널 아래 스위치예요. 같은 영상을 쓰는 다른 배너 카드 중 배치가 같은 카드는 한 장의 크기·위치를 고치면 함께 따라 맞춰져요. 한 장만 따로 움직이려면 대상 목록에서 그 카드를 눌러 빼세요(그 카드는 지금 값 그대로 남아요). 되돌리려면 목록에서 다시 누르거나, 뺀 카드를 열어 [다시 넣기]를 누르세요. 빠진 카드에는 렌더큐에서 빠짐 배지가 붙어요.
  4. 파일명 · 포맷 — 렌더큐의 대기 카드를 더블클릭하거나 우클릭하면(카드를 하나만 골랐다면 F2로도) 출력 설정이 열려요. 여기서 파일명과 mp4 · mov · gif · png 포맷을 잡마다 따로 정합니다. 해상도·용량·비트레이트·fps는 렌더큐 아래 ‘용량·화질 설정’에서 모든 잡에 일괄 적용돼요.
  5. 파일명 편집 · 선택 — 출력 설정의 [편집]을 누르면 파일명 편집 창이 열려, 이름을 날짜 · 광고주 · 캠페인 · 페이지 · 작업내용 · 해상도 · 작업자 · 작업종류 · 작업구분으로 나눠 지을 수 있어요. 순서는 규칙대로 자동으로 맞춰지고, 아래 미리보기에 실제로 만들어질 파일 이름이 그대로 나옵니다. 파일명에서 읽어낸 값이 확실하지 않으면 「추측」 배지가 붙어요 — 그 칸은 한 번 봐 주세요. 작업자는 이니셜을 한 번 넣어 두면 기억해서 다음부터 자동으로 채워져요. 페이지는 [−][+](또는 ↑ ↓)로, 캠페인·작업내용은 [+1]로 숫자를 올리고, 작업구분의 retuch를 누르면 수정 차수가 하나 올라가요(3 → 4). 해상도 목록(칸 옆 ⌄) · [오늘로] · 찾아 바꾸기 · [비우기](날짜·작업자만 남겨요)도 있어요. 비운 항목은 이름에서 빠집니다.
    여러 장 한꺼번에 — 대기 카드를 여러 장 고른 뒤 우클릭하거나 F2를 누르면, 고른 카드 전부에 페이지 · 작업자 · 작업종류 · 작업구분 · 찾아 바꾸기를 한 번에 얹을 수 있어요(retuch는 카드마다 자기 차수에서 하나씩 올라가요). 고른 항목만 기존 이름 뒤에 얹고, 여기서는 지울 수 없어요 — 지우려면 카드를 한 장씩 열어 [편집]을 쓰세요. 합성 잡과 완료 기록 카드는 여러 장 한꺼번에서 빠져요 — 합성 잡은 한 장씩 [편집]을 쓰시면 됩니다.
  6. 출력 위치 정하기 — 렌더 버튼 바로 위 출력 칸에서 저장할 곳을 먼저 정해요. 왼쪽 폴더 버튼으로 출력 폴더를 고르거나, 칸에 경로를 직접 붙여넣어도 됩니다. 정하지 않으면 렌더가 시작되지 않아요.
  7. 렌더 실행 · Enter — 로컬에서 ffmpeg가 돌고 진행률이 실시간으로 차올라요.
  8. 출력 폴더 열기 · M — 완성된 파일이 담긴 폴더를 바로 엽니다.
i음원 노드를 함께 연결하면 영상 + 배너 + BGM이 한 번에 합성돼요. 음원 노드를 더블클릭하면 파형 편집기가 열려 구간과 원본 교체 / 원본과 믹스, 음원 볼륨 · 원본 볼륨을 정할 수 있습니다(원본 볼륨은 「원본과 믹스」를 골랐을 때 펼쳐져요). 편집기 안에서는 Space=미리듣기, [=시작 · ]=끝, Shift+드래그=구간 새로 지정, Ctrl+휠=파형 확대. 영상 노드를 우클릭하면 렌더큐로 바로 보내기로 배너 없이 영상만 출력 잡으로 넣을 수도 있어요.
i여러 잡을 걸어 두면 기본은 한 번에 하나씩 순서대로 렌더돼요. 설정에서 동시 렌더 수를 올릴 수도 있지만, 렌더 하나가 이미 CPU 코어를 여러 개 쓰기 때문에 보통은 빨라지지 않아요 — 기본값을 권합니다.

렌더큐 — 대기와 기록

렌더큐는 두 칸이에요. 위는 지금 렌더할 대기 카드, 아래는 완료 · 실패 기록입니다.

  • 대기 카드 — 노드 연결에서 그때그때 만들어져요. 렌더가 끝나면 이 카드는 위에서 사라지고 아래 기록으로 내려갑니다. 렌더가 도는 동안 새로 연결한 작업도 바로 다음 렌더 카드로 나타나요 — 이번 렌더에는 들어가지 않고, 지금 렌더가 끝난 뒤 [렌더]를 다시 누르면 렌더돼요.
  • 기록 카드 — 렌더한 그 순간의 설정을 그대로 담고 있어요. 나중에 반복 횟수·구도·컷을 바꿔도 이미 끝난 카드는 바뀌지 않습니다. 파일 이름 · 걸린 시간 · 만든 시각이 그대로 남아요.
  • 결과물 바로 열기 — 기록 카드를 더블클릭하거나 썸네일을 클릭하면 만들어진 파일이 기본 플레이어로 재생돼요.
  • 기록 카드 우클릭 — 재생 · 출력 폴더 열기 · 다시 렌더 · 기록에서 지우기가 나와요. PNG 시퀀스는 파일이 아니라 폴더라 시퀀스 폴더 열기로 바뀝니다. 기록 카드에는 출력 설정이 없어요 — 이미 만들어진 파일의 이름은 큐에서 바꿔도 아무 일이 일어나지 않으니까요.
  • 한 번 렌더한 작업은 다시 돌지 않아요 — 렌더 버튼을 다시 눌러도 건너뜁니다. 설정을 바꿔도 자동으로 되살아나지 않으니, 다시 뽑고 싶으면 기록 카드를 우클릭 → 다시 렌더로 새 대기 카드를 만들어 주세요.
  • 기록은 프로젝트에 저장돼요 — 저장했다 다시 열면 완료 기록이 그대로 돌아옵니다. 구획 제목의 기록 비우기로 지워도 만들어진 파일은 그대로예요.
  • 더 새 버전에서 저장한 프로젝트 — 지금 앱보다 새 버전이 저장한 프로젝트를 열면 [그래도 열기] / [취소] 선택창이 먼저 떠요. 그대로 열어 저장하면 새 버전에서 추가된 설정이 빠지니, 앱을 업데이트한 뒤 여는 것을 권해요. 옛 앱에는 이 알림이 없어 경고 없이 열려요 — 새 앱으로 저장한 파일은 옛 앱으로 열지 마세요.
i대기 카드가 화면에서 사라지면(카드 삭제 · 큐 비우기 · 연결 해제 · 컷 해제 등) 그 카드에 지어 둔 파일 이름도 함께 버려져요 — 같은 작업을 다시 큐에 보내면 이름이 새로 지어집니다. 다만 포맷(mov · gif · png)은 남아 다음에도 그대로 적용돼요.

출력 포맷

  • mp4 · 기본값 — H.264 영상 + AAC 소리. 어디서든 잘 열려요.
  • mov — 화질·코덱 설정은 mp4와 완전히 같고 컨테이너만 QuickTime이에요. 알파(투명)나 ProRes로는 나오지 않습니다.
  • gif — 팔레트를 두 번 계산해 뽑는 고품질 움짤. 소리는 들어가지 않아요.
  • png — 파일 하나가 아니라 PNG 시퀀스예요. 출력 이름으로 폴더가 하나 생기고 그 안에 이름_0001.png부터 연번으로 쌓입니다. 소리는 없고, 같은 이름의 폴더가 있으면 뒤에 번호가 붙어요.
!gif · png는 소리가 담기지 않는 포맷이라 음원을 연결해 두어도 무시돼요. 목표 용량 · 비트레이트도 mp4 · mov에만 적용되니, gif · png는 fps로 용량을 조절해 주세요.

다운로드 · 설치

설치 없이 압축만 풀면 됩니다. 처음 한 번만 아래를 확인하면 돼요.

다운로드v1.0.204

무설치 — 압축만 풀면 바로 실행돼요. Windows는 BannerNode.exe 더블클릭.

접속 기기 확인 중…
Windows용 다운로드.zip macOS · Apple 실리콘준비 중 macOS · Intel준비 중

macOS 14.0(Sonoma) 이상이 필요해요. Apple 메뉴 ▸ 이 Mac에 관하여에서 확인하세요 — 그보다 낮으면 앱이 열리다 그냥 꺼집니다.
macOS 버전에서 이상한 점이 보이면 ADEF 담당자에게 알려 주세요.
어느 걸 받아야 하나요? 화면 왼쪽 위 Apple 메뉴 ▸ 이 Mac에 관하여에서 칩(Intel 맥은 프로세서) 줄을 확인하세요 — Apple M으로 시작하면(M1~M5 등) Apple 실리콘, Intel이 보이면 Intel입니다.
처음 열 때 경고창이 뜨며 안 열리는 건 정상이에요(애플 인증서가 없는 앱이라 뜨는 안내예요). 경고창에서 [휴지통으로 이동]은 누르지 말고, 아래 설치 안내 macOS 탭의 처음 한 번 열기대로 한 번만 허용하세요 — 터미널에 한 줄 붙여넣는 방법이 가장 확실해요.

  1. 압축 풀고 실행 — 받은 zip을 풀고 폴더 안의 BannerNode.exe를 더블클릭하면 앱 창이 뜹니다. 별도 설치 과정은 없어요. 보안 경고 창이 먼저 뜨면 아래 Windows 보안 안내대로 열어 주세요.
  2. 패스워드로 로그인 — 처음 켜면 로그인 화면이 떠요. 가운데 큰 버튼이 아니라 그 아래 작은 글씨 패스워드로 로그인을 누르고, ADEF에서 받은 패스워드(BNP-로 시작해요)를 넣은 뒤 입장을 누르세요. 한 번 들어가면 이 컴퓨터에 로그인이 저장돼 다음부터는 바로 열려요. 다만 앱을 켤 때마다 인터넷으로 패스워드가 유효한지 확인하므로 인터넷 연결이 필요합니다. 패스워드가 없거나 들어가지지 않으면 아래 자주 묻는 질문을 봐 주세요.
  3. 바로 사용 — 켜면 시작 화면에서 새 프로젝트를 만들거나 최근 프로젝트를 이어서 열어요. 왼쪽에 영상·배너를 불러오고, 캔버스에서 노드를 이어 렌더하면 됩니다.
!“Unhandled exception in script” 창이 뜨며 실행이 안 된다면 — 앱이 고장난 게 아니라, 인터넷에서 받은 zip을 탐색기로 압축 해제하면 안의 모든 파일에 “차단됨” 표시가 붙기 때문이에요. 앱이 시작할 때 스스로 풀어 주므로 보통은 그냥 실행하시면 됩니다.
그래도 이 창이 뜬다면, PowerShell(시작 메뉴에서 “PowerShell” 검색)에 아래 한 줄을 붙여넣고 엔터한 뒤 다시 실행하세요.
Get-ChildItem -Recurse "$env:USERPROFILE\Downloads\BannerNode-Windows" | Unblock-File
미리 막으려면 — 압축을 풀기 전에 zip 파일을 우클릭 ▸ 속성에서 아래쪽 “차단 해제”에 체크하고 확인을 누르세요.
i시스템 요구사항 — Windows 10/11 · Microsoft Edge WebView2 런타임 · 인터넷 연결. WebView2는 대부분의 PC에 이미 들어 있어서 따로 하실 일이 없어요. 다만 새로 받은 노트북처럼 초기 설정에 따라 빠져 있는 경우가 있는데, 그때는 앱이 켜지자마자 설치 링크를 안내해 드립니다(검은 화면만 남지 않아요). 새 PC를 받으시면 회사 IT 담당자에게 WebView2 런타임 포함을 요청해 두시면 가장 편합니다.
!처음 실행 시 Windows 보안이 앱을 막을 수 있어요 — 둘은 대응이 다릅니다.

화면 구성

화면은 크게 세 부분이에요. 왼쪽에서 소스를 고르고, 가운데에서 잇고, 오른쪽에서 결과를 관리합니다.

왼쪽 · 미디어 라이브러리

  • 미디어 라이브러리 — 불러온 영상 · 배너 · 음원이 종류별로 쌓여요. 카드에 마우스를 올리면 그 자리에서 미리보기가 재생되고, 카드를 고르고 Space를 누르면 크게 볼 수 있어요.
  • 카드를 캔버스로 드래그하면 노드가 만들어져요.

가운데 · 노드 캔버스

  • 영상 노드 → 배너 노드로 선을 연결. 연결 하나가 렌더 잡 하나예요. 연결선 위에 마우스를 올리면 가운데에 X가 떠요 — 누르면 그 연결만 끊기고, Ctrl+Z로 되돌릴 수 있어요.
  • 휠로 확대·축소. 가운데 버튼이나 Space를 누른 채 끌면 화면이 이동하고, 그냥 빈 곳을 끌면 범위 선택이에요. S로 화면 맞춤, W로 100% 보기.

오른쪽 · 렌더큐

  • 위쪽 대기 카드에 연결한 잡이 쌓이고, 진행률이 실시간으로 표시돼요. 대기 카드를 더블클릭하거나 우클릭하면 출력 설정이 열려 파일명과 포맷(mp4 · mov · gif · png)을 잡마다 따로 정합니다. 출력 설정의 [편집]은 파일명 편집 창을 열고, 대기 카드를 여러 장 고른 채 우클릭하면 고른 카드 전부에 쓰는 파일명 편집 창이 열려요. 자세한 내용은 01 참고
  • 렌더가 끝나면 아래 완료 · 실패 기록으로 내려가요. 기록 카드는 더블클릭 = 결과물 열기, 우클릭 = 재생 · 폴더 열기 · 다시 렌더입니다. 자세한 내용은 01 참고

소스 불러오기

영상과 배너, 음원(BGM)을 왼쪽 라이브러리에 담는 세 가지 방법.

  • 파일 추가 · D — 파일 선택창에서 영상·배너를 골라 추가.
  • 폴더 스캔 · A — 폴더 안의 영상·배너를 한 번에 담기. 창이 뜨면 가져올 폴더로 들어간 다음, 아무것도 고르지 말고 [열기]를 누르세요. 파일을 골라서 열면 그 파일만 담깁니다. 하위 폴더까지는 들어가지 않고, 음원은 담기지 않아요 — 음원은 파일 추가나 드래그로 넣어 주세요.
  • 드래그 앤 드롭 — 탐색기에서 파일을 앱 위로 끌어다 놓기. Windows에서는 원본을 복사하지 않고 그대로 참조해 용량과 상관없이 빠르고, 다 읽어 들인 뒤 카드가 한 번에 나타나요. 캔버스에 놓으면 그 자리에 노드까지 함께 만들어집니다.
i배너는 구멍이 투명하게(알파) 뚫린 PNG를 써야 그 자리에 영상이 비쳐요. 배너가 위, 영상이 아래에 깔립니다.
구멍 대신 반투명 그라데이션이 깔린 배너(하단 자막 바 같은)도 그대로 쓸 수 있어요 — 반투명 띠가 한쪽 면을 끝까지 채우고 있으면 앱이 알아보고 영상이 프레임 전체를 채우도록 잡습니다. 불투명 액자 안에 반투명 말풍선·글로우가 있는 배너는 전체가 아니라 액자 안쪽에 영상이 들어가요. 프로젝트를 열 때는 손으로 고치지 않은 배너의 영상 자리를 이 규칙으로 다시 잡고, 새로 잡은 배너가 있으면 몇 개인지 알려 줍니다. 다만 완전히 투명한 부분이 전혀 없는 이미지(알파가 아예 없거나 전 영역이 반투명)는 배너로 읽지 못해 ㄴ자 표시가 나타나지 않아요 — 알파가 살아 있는 PNG 로 다시 내보내 주세요.
  • 영상 영역 확인 · 조정 — 배너 카드를 크게 보기로 열면 영상이 들어갈 자리가 모서리 ㄴ자 표시로 보여요. 자동 인식이 어긋났다면 그 표시를 드래그해 직접 맞출 수 있습니다. 배너의 빈 영역 경계에 자석처럼 딱 붙고, Shift를 누른 채 끌면 가로·세로 한 방향으로만, Alt를 누르면 자석 없이 자유롭게 움직입니다. 하단 바의 초기화를 누르면 자동 인식값으로 되돌아가요.
  • 제품컷이 가로지른 구멍도 인식 — 투명 영역 위에 제품 사진이 얹혀 구멍이 둘로 갈라져 보이는 배너도 하나의 영상 영역으로 합쳐서 잡아요.
!원본 파일을 옮기거나 지우면 카드가 흐려지고 ‘연결 끊김’이 떠요. 불러온 소스는 사본을 만들지 않고 원본을 그대로 참조하거든요. 끊긴 카드가 있으면 렌더가 시작되지 않으니, 카드를 우클릭 → 파일 다시 연결로 되살려 주세요. 다시 연결해도 노드 연결과 음원 구간은 그대로 유지됩니다.

사이즈 · 용량 · 반복

같은 소스를 여러 규격·용량으로 뽑아내고, 러닝타임까지 맞추는 변형 기능.

사이즈 베리

  • 영상을 원하는 해상도로 리사이즈해요. 맞춤에서 [여백 두기](잘리지 않게 맞추고 가운데 정렬)와 [꽉 채우기](화면을 꽉 채우고 넘치는 쪽을 잘라요) 중에 고르고, 꽉 채우기면 남길 위치 9칸(기본 가운데)으로 어느 쪽을 남길지 정합니다.
  • 캔버스의 영상 노드를 우클릭 → 크기·배경 변환에서 켜요.
  • 타겟 크기는 2열 칩이에요 — 늘 보이는 8종(1080×1920 · 1440×2560 · 1080×1350 · 1440×1800 · 1080×1080 · 1440×1440 · 1920×1080 · 1200×1200)에 [더 보기]를 누르면 「그 밖의 크기」 6종이 더 펼쳐져요. 직접 입력 칸에는 1440x1800 · 1440*1800 · 4:5 1440처럼 넣고, 여러 개는 쉼표나 줄바꿈으로 이어요(/를 누르면 바로 그 칸으로). 여러 크기를 한 번에 고르면 크기마다 렌더 잡이 하나씩 만들어지고, 버튼에 적용 · 잡 N개로 표시돼요. 직접 적은 크기 · 고정한 크기 · 이 프로젝트에서 쓴 크기는 「내 크기」 줄에 모여요 — 그 줄의 칩을 우클릭하면 고정(8개까지)하거나 내 크기에서 뺄 수 있어요.
  • [여백 두기]일 때 남는 여백은 여백 배경으로 채워요(꽉 채우기에서는 여백이 없어 이 설정이 숨겨져요) — 비움 · 컬러 · 블러(영상) 중 선택. 블러를 고르면 블러 강도 · 어둡게를 슬라이더로, 가장자리 반복을 켬/끔(기본 켬)으로 조절할 수 있어요.

용량 베리

  • 파일 용량을 줄여요 — 해상도 · fps · 비트레이트로 조절.
  • 렌더큐 아래(렌더 버튼 위) 접이식 용량·화질 설정 패널에서 켜요 — 버튼을 누르면 위로 펼쳐집니다.
  • 목표 용량(MB)을 정하면 2-pass 인코딩으로 그 용량에 맞춰 뽑습니다.
i두 기능은 여는 곳이 달라요 — 용량 베리는 렌더 버튼 위(렌더큐 아래) 접이식 용량·화질 설정 패널(해상도 · 목표 용량 · 비트레이트 · fps), 사이즈 베리는 영상 노드 우클릭 → 크기·배경 변환입니다. 용량·화질 설정 값은 렌더큐의 모든 잡에 일괄 적용돼요. 해상도는 원본 방향에 맞춰 적용돼요 — 세로 영상에 1280×720을 고르면 720×1280 안으로 들어가고, 원본보다 크게 적으면 비율을 지키며 키웁니다. 렌더큐로 바로 보내기 카드도 이 해상도를 따르고, 사이즈 베리 잡에선 각 잡의 타겟 크기가 우선이에요.

영상 반복

  • 짧은 영상을 여러 번 이어 붙여 러닝타임을 늘려요. 매체가 요구하는 최소 초수를 맞출 때 씁니다. 3.2초 영상 × 4회 = 12.8초
  • 캔버스의 영상 노드를 우클릭 → 반복에서 켜요. 이미 반복이 걸린 노드는 오른쪽 위 반복 칩을 눌러도 같은 창이 열립니다. 2~30회 중에 고르고, 고르는 즉시 적용돼요.
  • 값은 소재마다 기억되고, 컷 구간이 잡혀 있으면 그 구간만(구간이 여러 개면 이어 붙인 결과를) 반복해요. 함께 연결한 음원도 끝까지 이어집니다.
  • 렌더큐 카드에 반복 배지가 떠서 렌더 전에 확인할 수 있어요.
!gif · png로 뽑는 작업에는 반복이 적용되지 않아요. 값은 그대로 두니, 포맷을 mp4 · mov로 되돌리면 다시 적용됩니다.
06

컷 편집

영상의 앞뒤를 다듬는 가벼운 트림. 프레임 단위로 정확하게.

  • 컷편집 — 영상을 우클릭 → 컷편집으로 시작·끝 구간을 지정해요. 구간을 여러 개 만들면 렌더할 때 시간 순서대로 이어 붙여 한 편으로 만들어요.
  • 크게 보기 — 영상 카드를 하나 고르고 Space를 누르면 큰 화면으로 열려요. 큰 화면에서 Space는 재생/정지, Esc는 닫기예요.
  • 프레임 이동 · 구간 지정 — A D(또는 ← →)로 한 프레임씩 이동하고, 원하는 지점에서 W(↑)로 시작, S(↓)로 끝을 찍어요 — 구간이 여러 개면 고른 구간의 시작·끝이에요. 컷편집 창 · 크게 보기 · 크기·배경 변환 · 합성 미리보기에서 모두 같습니다. 구간이 여러 개일 때 크게 보기와 합성 미리보기에서는 W/S가 막히고 「구간이 여러 개예요 — 컷편집에서 고쳐 주세요」가 떠요.
  • 필름스트립 — 타임라인에 영상 프레임이 깔려 어디가 어느 장면인지 보면서 자를 수 있어요. 양 끝 손잡이를 끌어 구간을 정합니다.
  • 여러 구간 · 컷편집 창 · 크기·배경 변환 — + 구간 추가 (재생 위치에)를 누르면 재생 위치에 2초짜리 구간이 생겨요. 구간 칩이나 트랙을 눌러 고르고, 칩의 ×로 그 구간을 뺍니다. 아래 요약에 「구간 N개 → 결과 X초 (원본 Y초)」가 나오고, 구간이 2개 이상이면 이어 붙인 결과 막대가 더 보여요.
  • 호버 스크럽 — 타임라인 위에 마우스를 올리면 그 지점 프레임이 확대 미리보기로 떠요.
  • 구간 해제 — Alt+X로 지정한 구간을 전부 지웁니다(구간이 여러 개여도 한 번에). 걸어 둔 구간을 지우면 버튼이 [구간 해제 · 적용]으로 바뀌고, 누르면 구간이 풀려요. 구간을 안 정하고 [적용 · 렌더큐 추가]를 누르면 잡이 생기지 않고 안내만 떠요.
  • 지정한 구간은 그 영상에 기억돼서, 배너·음원과 함께 렌더할 때도 그대로 적용돼요.

10

자주 묻는 질문

처음 켰더니 로그인하라고 떠요.

처음 한 번 ADEF에서 받은 패스워드로 로그인해야 해요. 로그인 화면 가운데 큰 버튼이 아니라 그 아래 작은 글씨 패스워드로 로그인을 누르고, BNP-로 시작하는 패스워드를 넣은 뒤 입장을 누르면 됩니다. 한 번 로그인하면 이 컴퓨터에 저장돼 다음부터는 바로 열리고, 앱을 켤 때마다 인터넷으로 패스워드가 유효한지 확인해요. 패스워드를 받지 못했거나 잊었다면 ADEF 담당자(이 설명서 주소와 패스워드를 전해 드린 분)에게 문의해 주세요. 로그아웃은 앱 설정 맨 위 계정 항목의 로그아웃 버튼으로 합니다.

켰는데 연결이 안 된다고 떠요.

BannerNode는 켤 때마다 인터넷으로 패스워드가 유효한지 확인해요. 그 확인이 안 되면 로그인 화면에 “서버에 다시 연결하는 중이에요…”가 뜨고 몇 초 간격으로 스스로 다시 시도합니다 — 잠깐 끊긴 것이라면 그대로 두면 열려요.
끝내 안 되면 “연결이 안 돼요. ADEF 담당자에게 문의해 주세요.”로 바뀝니다. 먼저 인터넷 연결을 확인한 뒤 앱을 다시 실행해 주세요. 저장된 로그인은 그대로 남아 있어서 패스워드를 다시 넣을 필요는 없어요.
패스워드를 넣고 입장을 눌렀을 때 같은 문구가 뜨면 인터넷 연결을 확인하고 그 자리에서 다시 입장을 눌러 주세요.
인터넷이 되는데도 계속 같다면 ADEF 담당자에게 문의해 주세요.

패스워드가 더 이상 안 돼요.

로그인 화면에 뜨는 문구에 따라 달라요.
“패스워드로 다시 입장해 주세요.” — 저장돼 있던 로그인이 풀린 것뿐이에요. ADEF에서 가장 최근에 받은 패스워드를 다시 넣으면 됩니다.
“패스워드가 올바르지 않아요.” — 오타일 가능성이 커요. 맨 앞의 BNP-까지 빠짐없이 넣었는지 확인하고, 받은 글자를 그대로 복사해 붙여 넣어 보세요.
“쓸 수 없는 패스워드예요. ADEF 담당자에게 문의해 주세요.” — 그 패스워드는 사용이 끝난 거예요. ADEF 담당자에게 문의해 주세요.
앱을 쓰는 도중에 “이 패스워드는 더 이상 쓸 수 없어요.” 알림이 뜨면 하던 작업은 그대로 이어서 할 수 있지만 다음 실행부터는 열리지 않아요. 지금 작업을 저장해 두고 ADEF 담당자에게 문의해 주세요.

새 버전은 어떻게 받나요?

새 버전이 나오면 앱을 켤 때 시작 화면에서 알려 줘요. 거기서 업데이트 받기를 누르면 앱이 직접 내려받고, 다 받은 뒤 화면 안내대로 다시 시작하면 새 버전으로 열립니다. 이 페이지의 다운로드 버튼으로 새로 받아 써도 돼요.

처음 켤 때 검은 화면이 잠깐 떠요.

새 버전을 처음 실행할 때 Windows 보안 검사 때문에 뜨는 데 몇 초 걸릴 수 있어요. 두 번째 실행부터는 빠르게 뜹니다.
아주 드물게 창이 계속 검게만 보일 때가 있어요(그래픽 합성이 어긋난 일시 현상) — 창 모서리를 살짝 드래그해 크기를 바꿔 보세요(가장 확실). 안 되면 좌상단 로고 클릭이나 F5, 그래도 안 되면 창을 닫고 다시 실행하면 됩니다.
검은 화면이 끝내 안 걷히면 잠시 뒤 안내창이 뜹니다 — 창에 적힌 대로 Microsoft Edge WebView2 런타임을 설치(또는 복구)해 주세요. 안내창이 광고 차단·보안 프로그램을 짚으면(창 제목 「BannerNode — 화면을 불러오지 못했어요」) 그 프로그램에서 BannerNode 와 Microsoft Edge WebView2 를 검사 대상에서 빼 주세요 — AdGuard 는 설정의 필터링 앱 목록에서 두 항목의 필터링을 끄면 되고, WebView2가 업데이트되면 한 번 더 꺼야 할 수 있어요. 그래도 같으면 %USERPROFILE%\.bannernode\boot_debug.log 를 ADEF 담당자에게 보내 주시면 원인을 바로 볼 수 있어요.

SmartScreen · 스마트 앱 컨트롤이 실행을 막아요.

SmartScreen이 막으면 추가 정보 → 실행. 스마트 앱 컨트롤(SAC)이 켜져 있으면 그 버튼이 없으니 Windows 보안 ▸ 앱 및 브라우저 컨트롤 ▸ 스마트 앱 컨트롤을 끄고 실행하세요 — 나중에 다시 켤 수 있어요(코드 서명이 없는 앱이라 뜨는 안내예요).

맥에서 “그래도 열기” 버튼이 안 보여요 / “손상되었기 때문에 열 수 없습니다”가 떠요.

이 설명서에서 받은 앱이라면 고장이 아니라 맥의 첫 실행 검사 때문이에요(다른 곳에서 받은 파일이면 열지 말고 ADEF 담당자에게 문의해 주세요). 경고창의 [휴지통으로 이동]은 누르지 마세요(이미 눌렀다면 휴지통에서 BannerNode를 응용 프로그램 폴더로 다시 끌어다 놓으면 돼요). [그래도 열기]는 앱을 열려다 막힌 뒤 약 1시간 동안만 시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 보안 칸에 생기고, “손상되었기 때문에” 창이 떴다면 아예 안 생길 수 있어요.
회사가 관리하는 업무용 Mac이면 아래 줄은 쓰지 말고, 위 설치 안내 macOS 탭의 방법 2를 ①부터 다시 해 본 뒤 버튼이 끝내 안 보이면 회사 IT 담당자나 ADEF 담당자에게 알려 주세요.
그 밖의 Mac은 앱이 응용 프로그램 폴더에 있는지 확인하고(없으면 먼저 그 폴더로 옮기고), 터미널(응용 프로그램 ▸ 유틸리티)에 아래 한 줄을 붙여넣어 return을 누른 뒤, 응용 프로그램 폴더의 BannerNode를 다시 더블클릭하세요.
xattr -dr com.apple.quarantine /Applications/BannerNode.app
그래도 안 열리면 다른 명령을 찾아 쓰지 말고 ADEF 담당자에게 문의해 주세요. 자세한 순서는 위 설치 안내의 macOS 탭에 있어요.

미리보기 파일이 디스크를 얼마나 먹나요?

썸네일·미리보기처럼 다시 만들 수 있는 파일은 미디어 캐시로 모이고, 설정 → 저장소의 최대 미디어 캐시 크기(기본 5 GB)를 넘으면 오래 안 쓴 것부터 자동으로 지워요. 반면 가져온 사본(끌어다 놓은 파일을 앱이 따로 복사해 둔 것)은 실제 소재라 자동으로 지우지 않습니다 — 직접 비우기를 눌러야 지워지고, 지우면 그 사본을 쓰는 소재의 연결이 끊겨요.
